# LookAway

LookAway 是一个面向 Windows 的轻量级护眼计时器。它通过系统键鼠空闲时长判断你是否仍在工作，并在达到设定的有效工作时长后显示置顶休息提醒。默认采用 45 分钟工作、5 分钟休息的节奏。

## 功能

- 工作时长可在 5～60 分钟之间调节，累计达到设定时长后提醒
- 休息时长可在 1～20 分钟之间调节，并提供休息倒计时
- 键鼠空闲超过 1 分钟时自动暂停累计，恢复操作后自动继续
- 连续空闲达到 5 分钟时清空本轮进度，回来后按当前设置重新计时
- 可在主界面齿轮按钮或系统托盘菜单中修改时长，设置按当前 Windows 用户保存
- 可开启开机自启：登录后在系统托盘静默运行，不弹出主窗口
- 每天完成至少 3 个完整工作与休息周期后获得 1 次抽卡机会，抽取护眼主题卡片
- 提供护眼收集册：展示 15 张卡片、重复卡数量和文章中的角色评论
- 提供用眼统计，可切换最近 7 天每日趋势和最近 24 小时分时趋势；悬浮数据点可查看精确时长，日记录保留 14 天
- 提供“5 分钟后提醒”，方便暂时推迟休息提醒
- 有效工作计时时播放 `working.gif`，暂停、空闲和休息时播放 `waiting.gif`
- 支持手动暂停、继续和重新计时
- 最小化主窗口时保留在任务栏，关闭主窗口后常驻系统托盘
- 不读取或记录按键内容、鼠标位置及任何工作内容，只在内存中更新最近一次键鼠活动时间

## 代码结构

- `src/main.cpp`：进程入口、单实例检查和 GDI+ 生命周期
- `src/app/`：应用编排、窗口配置、每日奖励和收集状态持久化
- `src/core/`：可独立测试的计时与用眼统计逻辑
- `src/platform/`：Windows 开机自启与命令行处理
- `src/ui/`：DPI 绘制、文字、统计标签、GIF 和卡片图片加载

## 直接运行

双击 `dist\LookAway.exe`。仓库当前构建出的程序也位于 `build\LookAway.exe`。

最小化主窗口时程序会保留在任务栏；关闭主窗口时程序会隐藏到系统托盘。要完全退出，请右键单击系统托盘中的 LookAway 图标并选择“退出”。

点击主界面右上角的齿轮按钮，或在系统托盘菜单中选择“计时设置”，可以修改工作和休息时长，以及是否开机自启。修改工作或休息时长后，当前计时周期会重新开始；仅切换开机自启不会重置计时。也可在托盘菜单中直接勾选或取消“开机自启”。

点击主界面顶部的统计按钮，或在系统托盘菜单中选择“用眼统计”，可以切换查看最近 7 天或最近 24 小时的用眼总计、平均时长、活跃时段和趋势。将鼠标悬浮在趋势数据点上，可以查看对应日期或小时的精确用眼时长。统计只累计有效工作时间，数据按当前 Windows 用户保存在本地。

每天完成第 3 个完整的工作和休息周期后，会获得 1 次抽卡机会；同一天完成更多周期不会重复发放抽卡机会，未使用的抽卡券可以保留到之后使用。打开主界面顶部的卡册按钮、系统托盘菜单中的“护眼收集册”，即可抽取卡片并查看收集进度。卡片和每日进度保存在当前 Windows 用户配置中；工作和休息需要在同一自然日内完成，提前结束休息或跨越午夜的周期不会计入当日进度。

护眼收集册目前包含 15 张卡片，图片和对应评论来自米游社文章[《3.1 活动「初代虚狩，回归」蕾米埃尔真迹全集+兄妹俩点评》](https://www.miyoushe.com/zzz/article/76782061)。来源说明仅保留在本 README 中，不在卡片详情界面重复展示；该页面为用户投稿，公开发布前请同时遵守游戏运营方、米游社及投稿内容的使用规则。

## 从源码构建

需要 Windows 10/11、CMake 3.20 及以上版本，以及 MSVC 或 MinGW C++ 编译器。在 PowerShell 中运行：

```powershell
.\build.ps1
```

脚本会构建应用、运行测试，并将可执行文件安装到 `dist\LookAway.exe`。

也可以手动执行：

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

LookAway 只提供定时提醒，不能替代医生的检查和治疗建议。
